# C++ من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لتعلم لغة C++ من الصفر تماماً، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/cpp-from-zero/

## المحتوى

- **14 درس متدرج** (13 درس + مشروع ختامي): من "ليه C++ أصلاً؟" لحد مشروع console كامل
- **42 سؤال تفاعلي** بتصحيح فوري وشرح لكل إجابة
- **28 تمرين عملي** بمحاولات وكشف حل نموذجي
- **معمل C++ تفاعلي** داخل المتصفح: محاكي C++ مكتوب بـ JavaScript خالص بيفهم 14 بنية من اللغة (تعريف متغيرات بأنواع int/double/string/bool/char، عمليات حسابية بالقسمة الصحيحة الحقيقية، شروط if/else، حلقات for/while/do-while، طباعة cout، وإدخال cin بطابور مدخلات) مع 10 مهام موجهة بتتصحح تلقائياً، ولوحة بتوضح حالة المتغيرات لحظة بلحظة
- تتبع تقدم محلي (localStorage) لكل درس وسؤال وتمرين

## الدروس

1. ليه C++ أصلاً؟
2. تجهيز الأدوات (المترجم والمحرر)
3. أول برنامج: Hello World
4. المتغيرات والأنواع
5. الإدخال والإخراج (cin و cout)
6. الشروط (if / else)
7. اللوبات (for / while)
8. Arrays و Strings
9. الـ Functions
10. الـ Pointers بالحدس
11. الـ Structs
12. أساسيات OOP
13. مقدمة STL (vector و map)
14. المشروع الختامي: نظام درجات الطلبة

## التقنية

صفحة واحدة (index.html) بدون أي build: HTML + CSS + JavaScript خام، محاكي C++ مكتوب بالكامل بـ JavaScript (lab-core.js + lab.js) من tokenizer و parser و interpreter، خلفية متحركة مشتركة (sams-bg.js)، وتصميم داكن متجاوب مع الموبايل.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو:

```bash
python3 -m http.server 8000
# وافتح http://localhost:8000
```
